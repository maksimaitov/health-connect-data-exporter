# Health Connect Data Exporter

[English README](../README.md)

Небольшое open-source приложение для Android, которое выгружает сырые записи из
Health Connect. Оно не привязано к производителю телефона или носимого устройства:
источником могут быть умные часы, кольцо, пульсометр, весы или фитнес-приложение,
если они передают данные в Health Connect.

Приложение работает только на чтение, не запрашивает доступ к интернету и обрабатывает
данные локально. Результат можно сохранить с телефона как ZIP-архив через стандартное
меню Android.

## Какие данные экспортируются

- пульс и пульс в покое;
- вариабельность сердечного ритма HRV (RMSSD);
- сессии и фазы сна, если источник передал фазы в Health Connect;
- насыщение крови кислородом и частота дыхания;
- шаги, дистанция и калории;
- тренировки, круги и сегменты;
- вес и рост;
- VO2 max;
- метаданные источника и устройства.

Каждый тип сохраняется в отдельном NDJSON-файле. `manifest.json` содержит количество
записей и ошибки. По кнопке **Share latest export** приложение создаёт единый ZIP-архив.

## Совместимость

- Android 9 или новее;
- сервисы Google Play;
- Health Connect: отдельное приложение на Android 9–13 или системный компонент на Android 14+;
- приложение-источник, которому разрешена запись в Health Connect.

Марка телефона значения не имеет. Если производитель часов или приложение не передали
определённый показатель в Health Connect, экспортёр не сможет получить его из закрытой
базы этого приложения.

## Установка через Android Studio

1. Клонируйте репозиторий и откройте его в актуальной Android Studio.
2. Дождитесь синхронизации Gradle и установки компонентов Android SDK.
3. Подключите телефон с включённой отладкой по USB.
4. Выберите конфигурацию `app` и нажмите **Run**.

## Сборка и установка из терминала

Потребуются JDK 17, Android SDK 36 и `adb`.

```bash
git clone https://github.com/maksimaitov/health-connect-data-exporter.git
cd health-connect-data-exporter
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Получение данных

1. Откройте **Health Connect Data Exporter**.
2. Нажмите **Grant access & export**.
3. Разрешите чтение нужных категорий и исторических данных.
4. Дождитесь сообщения о завершении.
5. Нажмите **Share latest export** и сохраните ZIP-архив.

Данные никуда не отправляются автоматически. Не публикуйте полученный архив: он может
содержать подробную историю здоровья и идентификаторы приложений-источников.

## Ограничения

- Экспортируется только то, что приложения-источники записали в Health Connect.
- Маршруты тренировок пока не выгружаются: для координат требуется отдельное согласие.
- Поддерживается набор распространённых типов данных, перечисленный выше, а не абсолютно
  все типы развивающегося API Health Connect.
- Health Connect не работает внутри рабочего профиля Android.
